Mechanical Design of a Robotic Dog
Project Overview

This project presents the mechanical design of a quadruped robotic dog developed during the first mechanical engineering task. The robot was designed to simulate the movement of a dog using a simple and lightweight structure that provides stability and flexibility.

The design process included creating a complete 3D model and exporting all required parts as STL files for manufacturing and future development.

Design Objectives
Design a stable and lightweight robotic dog.
Create a simple mechanical structure for four-legged movement.
Develop a modular design that can be easily modified and assembled.
Prepare the model for 3D printing by exporting the components as STL files.
Robot Components

The mechanical design consists of the following parts:

Main body (chassis)
Four legs
Joint connections
Structural support components
STL files for all individual parts
Design Software

The robotic dog was designed using CAD software to create the 3D model and generate the STL files required for fabrication and assembly.
